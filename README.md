# First PR Practice

This is a small practice repository for learning how to open a pull request on GitHub.

## What this is

A minimal repo to try out the workflow: branch, commit, push, open PR, merge.

## Klotz Kaskade (game)

`game/index.html` is a small block puzzle game: drag the three pieces onto the 8×8 board and fill complete rows or columns to clear them. It has a daily challenge (same board for everyone each day, with a day streak), an endless mode and 10 levels with stone blocks, line goals and star ratings. Sound effects and background music are synthesised and can be toggled separately, and particle effects respect reduced-motion settings. After 20 minutes of play it suggests a break. It is a single HTML file with no dependencies, so open it in any browser to play.
