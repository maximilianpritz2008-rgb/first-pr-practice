# First PR Practice

This is a small practice repository for learning how to open a pull request on GitHub.

## What this is

A minimal repo to try out the workflow: branch, commit, push, open PR, merge.

## Klotz Kaskade (game)

`game/index.html` is a small block puzzle game: drag the three pieces onto the 8×8 board and fill complete rows or columns to clear them. It has an endless mode and 10 levels with stone blocks and a line goal, plus synthesised sound effects (toggle with the speaker button). It is a single HTML file with no dependencies, so open it in any browser to play.
