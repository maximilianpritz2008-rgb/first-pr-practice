# Das sättigendste Lebensmittel

Laut dem "Satiety Index" (Sättigungsindex) von Dr. Susanna Holt (University of
Sydney, 1995) sind **gekochte Kartoffeln** das sättigendste getestete
Lebensmittel. Als Referenzwert (Index 100) diente Weißbrot.

## Ergebnisse (Auszug)

| Lebensmittel        | Sättigungsindex |
|---------------------|-----------------|
| Gekochte Kartoffeln | 323             |
| Fisch               | 225             |
| Haferflocken        | 209             |
| Orangen             | 202             |
| Eier                | 150             |
| Weißbrot (Referenz) | 100             |
| Croissant           | 47              |

Je höher der Wert, desto stärker das Sättigungsgefühl pro Kalorie im
Vergleich zu Weißbrot.

Quelle: Holt, S. H., Miller, J. C., Petocz, P., & Farmakalidis, E. (1995).
*A satiety index of common foods.* European Journal of Clinical Nutrition,
49(9), 675–690.
